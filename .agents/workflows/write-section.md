# Write one lecture question

1. Identify one `section_N.json` brief and activate `section-authoring`, `document-numbering`, `formula-governance` and citation skills.
2. Write exactly one `section_N_slug.md` with the brief's `L.Q` question heading and `L.Q.S` subsection headings.
3. Include coherent theory, evidence-backed formulas, assumptions, units, core example, misconception and numbered micro-conclusion.
4. Do not write mnemonic/callout inserts, image prompts, graph specs, other sections or global formula numbers.
5. Validate citations, formula labels, heading numbering, claims, budget and bridges.

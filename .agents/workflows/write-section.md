# Write one lecture section

The user or orchestrator must identify exactly one section number N.

Activate `section-authoring`, `formula-governance` when formulas are required, and `gost-citation`. Read only the corresponding section brief, blueprint, evidence ledger, bibliography, glossary and config. Write exactly one file `output/sections/section_{N}_{slug}.md`.

Use stable source citations and formula labels. Do not assign final formula numbers. Do not assemble the whole lecture or edit another section. Verify the section structure, evidence coverage, bridge text, definitions, examples, limits and conclusion before finishing.

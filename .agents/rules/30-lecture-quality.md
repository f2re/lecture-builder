# Lecture quality model

A lecture is one coherent argument, not a concatenation of independent articles.

For every section use this reasoning sequence:

1. Connect the section to already established knowledge.
2. State the local question or problem.
3. Define new terms before using them analytically.
4. Explain physical, scientific or methodological meaning.
5. Introduce formalism and formulas only after motivation.
6. State assumptions and applicability limits.
7. Work through an example that uses the introduced model.
8. Address at least one likely misconception when relevant.
9. Derive a short conclusion from the section.
10. Create a content-specific bridge to the next question.

Quality requirements:

- one main idea per paragraph;
- no repeated definitions or boilerplate transitions;
- no term before its definition or required prerequisite;
- explicit cause–effect, general–specific, observation–model and theory–application links;
- formulas followed by symbol definitions, units and interpretation;
- examples linked to the preceding theory;
- conclusions contain no new facts;
- language is academic, precise and readable for the configured audience;
- headings, terminology, notation and abbreviations remain consistent across the lecture.

# Methodical and visual quality

- Enrichment supports comprehension, memory, application, transfer or self-check; it must not decorate every paragraph.
- Use a restrained common callout grammar: key idea, mnemonic, thematic example, formula reading, common mistake, self-check, comparison, professional context and visual cue.
- A mnemonic must map back to the scientifically correct concept and must not introduce a false causal, spatial or mathematical relation.
- Fact-bearing callouts use verified claims/evidence. Invented numerical scenarios are visibly marked as illustrative.
- Every quantitative graph is generated deterministically from cited/local data. A qualitative graph is marked `schematic` and visibly states that it is not observational data and not necessarily to scale.
- Graph axes, units, transformations, captions and alt text are mandatory. Generated graph assets must match `chart_specs.json` and `figures_index.json` hashes.
- Prompts for non-chart figures remain in the separate `output/image_prompts.md`; they never replace source-backed text or deterministic data plots.
- Scientific and pedagogical reviewers inspect methodical inserts, graph specifications, captions and numbering as part of the lecture.

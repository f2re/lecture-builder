# Methodical callout library

Use one visual grammar throughout the lecture:

| Type | Visible label | Primary function |
|---|---|---|
| `key_idea` | **Ключевая идея.** | compress the concept |
| `mnemonic` | **Мнемоника.** | support recall |
| `thematic_example` | **Тематический пример к вопросу L.Q.** | connect theory and context |
| `formula_reading` | **Как читать формулу.** | translate notation into meaning |
| `common_mistake` | **Типичная ошибка.** | prevent misconception |
| `self_check` | **Проверка понимания.** | retrieval or transfer |
| `comparison` | **Сопоставление.** | distinguish close concepts |
| `professional_context` | **Профессиональный контекст к вопросу L.Q.** | show disciplinary use |
| `visual_cue` | **Зрительная опора.** | create a correct spatial cue |

Do not number these callouts as structural subsections. Their stable `insert_id` is kept only in an HTML comment, so the visible hierarchy remains clean: questions `L.Q`, subsections `L.Q.S`, formulas and figures `L.N`.

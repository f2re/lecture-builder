# Pedagogical review checklist

- [ ] Objectives are measurable and covered
- [ ] Prerequisites and concept order are valid
- [ ] Every new term is introduced before use
- [ ] Logical bridges are content-specific
- [ ] Examples apply the preceding theory
- [ ] Misconceptions are anticipated
- [ ] Paragraphs carry one main idea
- [ ] Volume fits allocated time
- [ ] Control questions span multiple cognitive levels
- [ ] Conclusion synthesizes without new content

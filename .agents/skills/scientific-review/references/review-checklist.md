# Scientific review checklist

- [ ] Every substantive claim resolves to evidence
- [ ] No fabricated metadata, quotation or page
- [ ] Formula algebra and dimensions are correct
- [ ] Symbols and units are defined consistently
- [ ] Assumptions and limits are stated
- [ ] Examples calculate correctly
- [ ] Terminology matches the discipline
- [ ] Current claims use current evidence
- [ ] Uncertainty and disagreement are represented
- [ ] Conclusions do not exceed the evidence

# Входные данные

`lecture_config.md` — единственный обязательный файл. Он валидируется схемой `contracts/lecture-config.schema.json`.

Дополнительные входы:

- `existing_refs.md` — заранее известные источники или DOI;
- `literature/` — локальные PDF, DOCX, EPUB, Markdown и текстовые файлы;
- другие пользовательские материалы, на которые явно ссылается конфигурация.

Агенты не должны изменять, удалять или заменять пользовательские входные данные. Единственное допустимое автоматическое изменение — создание нового файла из `lecture_config.example.md` при явном запросе пользователя.

# Входные данные

`lecture_config.md` — обязательный YAML-файл. `lecture_number` задаёт видимую нумерацию: для лекции 17 вопросы записываются как `17.1`, `17.2`, а subsections генерируются как `17.1.1`, `17.1.2`.

Дополнительные входы:

- `existing_refs.md` — заранее известные источники или DOI;
- `literature/` — локальные PDF, DOCX, EPUB, Markdown и текстовые файлы для сверки и fact check;
- другие пользовательские материалы, на которые явно ссылается конфигурация.

Блок `methodical` управляет количеством тематических примеров, мнемоник и self-check вставок. Блок `visuals` управляет графиками, фигурами и отдельным пакетом image prompts.

Агенты не должны изменять, удалять или заменять пользовательские входные данные. Мигратор создаёт новый файл или резервную копию только по явному запросу.
